# Tanot Solutions — Homepage

Static homepage: `index.html` + `style.css`, `footer.css`, `sections.css` and `app.js`.

## Run locally

```bash
python3 -m http.server 8000
```

Open http://localhost:8000/ (serve the folder; `app.js` is an ES module and won't load over `file://`).

## Files

- `index.html` — page content
- `style.css` — base design (header, hero, reviews, case study, services, why us, estimator, founder)
- `footer.css` — closing CTA and footer
- `sections.css` — video review, awards, team, featured on, FAQ, blog, plus layout fixes
- `app.js` — strategy form steps, estimator, mobile menu, scroll animations, footer clock
- `images/` — logo, founder photo, award images
